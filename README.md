# 古琴减字谱打谱工作台

面向音乐学院古琴打谱课的减字谱刻本识别工具。扫描刻本后完成 **朱墨分色 → 版面切分 → 减字部件拆解 → 音高推算** 全链路，识别与拆解运行在 Web Worker 内，刻本与部件标注绘制在 Canvas 上，全部使用 TypeScript。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm run build      # 类型检查 + 生产构建（Worker 独立分包）
npm test           # 全部测试（单元 + 端到端，含 Canvas 垫片）
```

端到端测试依赖 `canvas`（node-canvas）与 `jsdom`，安装时若遇 peer 冲突用
`npm install --legacy-peer-deps`。

## 四个工作页面

1. **刻本导入页**：程序化合成带部件级真值的刻本（三种字体 × 三档退化），或上传外部扫描图；一键在 Worker 中运行识别管线。
2. **版面切分页**：原图 / 墨色层 / 朱笔层切换，叠加显示版框、列框、行格线、切字框。
3. **减字拆解页**：点选任一减字，高亮七个部件分区与识别标签，对照真值、查看置信度，可人工修正任一槽位并重算承前消解与音高；底部为准确率评测面板。
4. **音高谱页**：按阅读顺序列出每音的弦、徽位、指法、频率、音名与音分偏差；支持四种定弦切换、WebAudio 试听、CSV/JSON 导出。

## 减字的逻辑结构

一个减字由固定归一化分区的七个槽位拼合（见 `src/vision/vocab.ts` 的 `ZONES`）：

| 槽位 | 含义 | 取值 |
|---|---|---|
| `kindMark` | 发声标记 | 散 `san` / 泛 `fan`（按音不标） |
| `leftFinger` | 左手指法 | 大/食/中/名 |
| `hui` | 徽位 | 1–13 徽（含几分）、徽外(14) |
| `right` | 右手指法 | 抹/挑/勾/剔/打/摘/轮/拨 |
| `string` | 弦序 | 一至七弦 |
| `orn1` / `orn2` | 装饰记号 | 绰/注、吟/猱/逗/撞 |

## 核心模块

```
src/domain/   纯领域逻辑（无 DOM 依赖，可单测）
  hui.ts        徽位 → 有效弦长比（十三徽谐波节点 + 徽分线性插值）
  tuning.ts     四种定弦、散/按/泛音频率、音名换算
  resolver.ts   承前消解状态机（同列省略部件沿用上一字）
  evaluator.ts  逐槽位/整字/音高的真值评测
src/synth/    合成刻本（带真值）
  sequence.ts   减字序列与省略写法生成、版面几何
  render.ts     Canvas 渲染 + 噪点/断笔/模糊/朱笔退化
  glyphs.ts     程序化部件笔画库（合成与识别模板同源）
src/vision/   视觉管线（Worker 内运行）
  colorSep.ts   朱墨分色
  layout.ts     版框/列/行格检测、网格切字
  recognizer.ts 多模板双向覆盖率匹配 + 形态学变体
  pipeline.ts   管线编排
  pipeline.worker.ts  Web Worker 入口
```

## 识别方法

- **合成与识别同源**：部件字形由 `glyphs.ts` 的矢量笔画程序化生成，合成器渲染刻本、识别器渲染模板，共用同一套字形定义。
- **三种刻本字体**：方体/圆体/瘦体，差异在笔画粗细、转折圆度与倾斜。
- **模板匹配**：每个候选标签生成亚像素平移 + 腐蚀/膨胀形态学变体，对提取块做两级膨胀软匹配的双向覆盖率 F1。
- **省略写法**：分区墨覆盖率判空，再由承前消解状态机补全。

## 音高推算

- 按音：`f = 空弦频率 / 有效弦长比 r`，十三徽按谐波节点 1/8…7/8 定位，徽分在相邻整徽间线性插值。
- 泛音：`f = n × 空弦频率`，n 为该徽谐波序数（仅限整徽）。
- 散音：即空弦频率。
- 内置正调、慢角、蕤宾、清商四种定弦。

## 指标现状（端到端测试实测，240 字/组合 × 3 种子）

测试在 Node 下用 node-canvas 复刻浏览器 Canvas 运行，数值见 `tests/e2e.pipeline.test.ts`：

| 指标 | 清晰 | 一般退化 | 漫漶 |
|---|---|---|---|
| 部件识别正确率 | ~91% | ~83–85% | ~78–86% |
| 省略判空正确率 | 100% | 100% | ~96% |
| 整字完全正确率 | ~70–76% | ~53–61% | ~43–58% |
| 单页耗时 | < 0.5s | < 0.6s | < 0.9s |

**说明**：本系统的字形与退化均为程序化合成的示意数据，并非真实明清刻本扫描件。
在这种可控合成数据上，清晰页部件正确率约 91%、端到端耗时远低于 3 秒目标；
但在模拟漫漶（断笔+模糊+噪点）下，部件正确率降至约 8 成、整字完全正确率约 4–6 成，
**尚未达到任务设想的部件 ≥95%、整字 ≥90%**。主要瓶颈是带分徽位复合字与形近右手指法在
强退化下的模板串匹配。要在真实刻本上达到该指标，需要引入真实标注样本与更强的识别模型
（如分区 CNN/度量学习），当前的同源模板匹配框架已预留了分区几何与真值标注接口，可平滑替换识别后端。
